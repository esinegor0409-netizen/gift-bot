# Gift Analytics Bot

Telegram-бот для аналитики NFT-подарков (star gifts): поиск, отслеживание владельцев, платная подписка через Telegram Stars.

## Структура проекта

- `bot.py` — основной бот (aiogram), команды и приём оплаты
- `collector.py` — сборщик данных о подарках через userbot-аккаунт (Pyrogram)
- `database.py` — работа с SQLite
- `config.py` — настройки (токены, цены)
- `requirements.txt` — зависимости

## Настройка

### 1. Получить токен бота
Напиши [@BotFather](https://t.me/BotFather) в Telegram → `/newbot` → скопируй токен.

### 2. Получить API_ID и API_HASH для userbot-сборщика
Зайди на https://my.telegram.org → API development tools → создай приложение → скопируй `api_id` и `api_hash`.

### 3. Настроить переменные окружения
Задай переменные (через `.env`, панель хостинга или прямо в `config.py`):

```
BOT_TOKEN=твой_токен_от_botfather
API_ID=твой_api_id
API_HASH=твой_api_hash
PHONE_NUMBER=+7999...
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Запуск бота

```bash
python bot.py
```

### 6. Запуск сборщика данных (отдельно, по расписанию)

При первом запуске Pyrogram попросит код подтверждения из Telegram (придёт в само приложение) — это нормально, аккаунт авторизуется один раз и сохранит сессию.

```bash
python collector.py
```

Список пользователей для отслеживания задаётся в `USER_IDS_TO_TRACK` внутри `collector.py`, либо можно доработать код, чтобы он подгружался из базы (например, из таблицы зарегистрированных пользователей бота).

## Деплой на Railway (запуск через сайт, без консоли)

1. Залей этот проект в репозиторий на GitHub
2. Зайди на [railway.app](https://railway.app) → New Project → Deploy from GitHub repo
3. Выбери репозиторий, Railway сам определит Python и установит зависимости
4. В настройках проекта (Variables) добавь переменные окружения: `BOT_TOKEN`, `API_ID`, `API_HASH`, `PHONE_NUMBER`
5. В настройках Start Command укажи: `python bot.py`
6. Для сборщика данных можно создать второй сервис в том же проекте со Start Command `python collector.py`

## Оплата через Telegram Stars

Подписка оформляется командой `/subscribe` — бот присылает счёт в звёздах (XTR). Отдельный платёжный провайдер не нужен: Stars — встроенная валюта Telegram, `provider_token` для неё оставляют пустым.

## Важно

- Сбор данных идёт через обычный аккаунт (userbot), а не через Bot API — у ботов нет доступа к данным о подарках других пользователей.
- Не увеличивай частоту запросов сверх разумной — риск ограничений на аккаунте.
- Точные raw-методы Telegram API для подарков могут со временем меняться — если `collector.py` выдаст ошибку метода, проверь актуальную документацию на core.telegram.org.
